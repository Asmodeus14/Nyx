# Nyx quantum provider credentials — TEMPLATE
#
# Copy this to `quantum-credentials.txt` (which .gitignore excludes) and fill it in. `Build.sh`
# bakes that file into the boot image as /mnt/nvme/etc/quantum-credentials.baked, so the keys are on
# the machine at every boot with nothing to type.
#
#     cp quantum-credentials.example.txt quantum-credentials.txt
#
# ★ Why build-time and not a settings field: Nyx has no clipboard and cannot express a paste chord,
#   and an IBM CRN is ~120 characters. See docs/quantum/remote.md.
#
# ⚠️ NEVER rename this to remove `.example` and commit it, and never paste a key into source.
#    `git log -p` keeps a deleted line forever.
#
# ⚠️ Nyx has NO permission model — `struct Process` has no uid and no syscall checks caller
#    identity. Any process on the machine can read these. Use scoped tokens you can revoke.
#
# Format: `key = value`, one per line. `#` starts a comment. Blank lines are ignored.
# Only the first `=` splits, so a CRN's own colons and slashes survive intact.


# ── IonQ ─────────────────────────────────────────────────────────────────────────────────────────
# https://cloud.ionq.com/settings/keys
#
# One credential, one header. Targets: `simulator` (free, and still a CLASSICAL simulation) or a
# `qpu.*` name such as `qpu.aria-1` (real trapped-ion hardware, METERED — it costs money per shot).

# ionq.token = your-ionq-api-key


# ── IBM Quantum ──────────────────────────────────────────────────────────────────────────────────
# https://quantum.cloud.ibm.com  →  your account page for the API key, and the instance page for the
# CRN.
#
# ★ Worth the extra setup: the Open plan includes 10 free minutes per 28 days on REAL QPUs. A Bell
#   pair at 1024 shots is a few seconds, so that is a lot of genuine measurements.
#
# ⚠️ IBM needs BOTH values. The key alone authenticates nothing — every request also carries the
#    instance CRN in a `Service-CRN` header, and a missing CRN fails in a way that looks like a bad
#    key. Nyx names them separately in its error messages for exactly that reason.
#
# ⚠️ Nyx can only run circuits it can place WITHOUT SWAP routing on IBM's heavy-hex lattice — Bell
#    pairs and GHZ chains. Anything else is refused by name rather than mis-compiled. See
#    docs/quantum/remote.md.

# ibm.token = your-ibm-cloud-api-key
# ibm.crn   = crn:v1:bluemix:public:quantum-computing:us-east:a/0123456789abcdef::
